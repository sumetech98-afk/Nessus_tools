01 · INTRODUCTION

🔧 What Is Nessus?

Nessus is a proprietary vulnerability scanner developed by Tenable, Inc. First released in 1998 by Renaud Deraison, it has grown to become the world's most widely deployed vulnerability assessment tool. Security professionals, sysadmins, and penetration testers use it to identify misconfigurations, missing patches, and vulnerabilities across their networks.

Nessus works by remotely scanning hosts — checking for thousands of known vulnerabilities, weak configurations, and compliance issues. It maintains a plugin database of over 180,000 plugins covering everything from missing Windows patches to default credentials to web application flaws.

For ethical hackers, Nessus is a critical tool in the vulnerability assessment phase of a penetration test. It helps you quickly identify low-hanging fruit, prioritize targets, and build a comprehensive view of the attack surface.

💡 Note: Nessus is a vulnerability scanner, not an exploitation tool. It identifies potential weaknesses — it doesn't exploit them. That's where tools like Metasploit come in.

04 · INSTALLATION

⬇️ Installing Nessus on Kali Linux

Step 1: Download the Installer

Go to tenable.com/downloads/nessus and download the Debian package for your architecture (amd64).

Step 2: Install Nessus

# Install the .deb package sudo dpkg -i Nessus-10.x.x-debian10_amd64.deb # Fix any missing dependencies sudo apt install -f # Start the Nessus service sudo systemctl start nessusd sudo systemctl enable nessusd # Check status sudo systemctl status nessusd

Step 3: Access the Web Interface

Open your browser and navigate to:

https://localhost:8834
💡 Note: Nessus uses HTTPS with a self-signed certificate — you'll need to accept the security warning in your browser. The default port is 8834.
05 · INITIAL SETUP

⚙️ Initial Setup & Activation

  1. Welcome screen — Choose "Nessus Essentials" for the free version.
  2. Get activation code — Enter your email; Tenable will send you a code instantly.
  3. Create admin account — Set a strong username and password.
  4. Wait for plugin download — Nessus will download and compile its plugin database (10-20 minutes on first run).
  5. Ready to scan — Once plugins are loaded, you'll reach the main dashboard.
# If plugin compilation takes too long, check logs sudo tail -f /opt/nessus/var/nessus/logs/nessusd.messages # Restart Nessus if needed sudo systemctl restart nessusd
⚠️ Warning: Don't interrupt the plugin compilation. It can take up to 30 minutes on slower systems. If it fails, restart the service and it will resume.

Unauthenticated vs Authenticated Scans

🌐

Scans from outside — checks services, banners, and known vulnerabilities. Faster but limited.

08 · YOUR FIRST SCAN

🚀 Running Your First Scan

  1. Click "New Scan" — Top-right corner of the Nessus dashboard.
  2. Choose "Basic Network Scan" — Good starting point.
  3. Name and describe — Give it a meaningful name like "Lab Scan 2025".
  4. Add targets — Enter IPs, ranges, or hostnames:
    • Single IP: 192.168.1.10
    • Range: 192.168.1.1-20
    • Subnet: 192.168.1.0/24
    • File: upload a list of targets
  5. Configure credentials — Optional but recommended (SSH/SMB/Windows).
  6. Save and launch — Click "Save" then "Launch".
  7. Wait for completion — Watch progress in the "My Scans" view.
Example Scan Configuration: ─────────────────────────────── Name: Lab Network Scan Policy: Basic Network Scan Targets: 192.168.1.0/24 Schedule: On Demand Email: you@example.com
09 · ADVANCED CONFIG

⚙️ Advanced Scan Configuration

Performance Settings

  • Max concurrent checks per host — Higher = faster but more aggressive.
  • Max simultaneous hosts — How many hosts to scan in parallel.
  • Network timeout — How long to wait for responses (default 5 sec).
  • Throttle scan — Reduce network load on production networks.

Port Scanning

  • Port range — Default is 1-65535 (full scan). Use "Common ports" for fast scans.
  • Scan type — SYN, TCP Connect, or UDP. SYN is stealthier.
  • Use Nmap — Nessus can use its own scanner or invoke Nmap.

Credentials

  • SSH — Username/password or key-based authentication.
  • SMB / Windows — Domain, username, password, or hash.
  • Kerberos — For AD environments.
  • SNMP — Community string for network devices.
  • Database — MySQL, Oracle, PostgreSQL, MSSQL.

Compliance & Plugins

  • Disable specific plugin families — Speed up scans by turning off irrelevant checks.
  • Enable compliance checks — PCI DSS, HIPAA, CIS Benchmarks.
  • Safe checks — Enable to avoid crashing fragile systems.
# Example advanced scan settings Max Hosts = 30 Max Checks/Host = 15 Network Timeout = 10 sec Port Range = 1-65535 Scan Type = SYN Safe Checks = Enabled Throttle = Disabled

Reading a Finding

Each finding in Nessus contains:

  • Plugin ID — Unique identifier for the check
  • Severity — Critical/High/Medium/Low/Info
  • Description — What the vulnerability is
  • Solution — How to fix it
  • Risk Information — CVSS score, impact
  • Vulnerability Information — References (CVE, CWE, etc.)
  • Output — Raw evidence of the finding
  • Port / Protocol — Where it was found

Prioritization

  1. Critical + High — Fix these first. They're exploitable.
  2. Remote + authenticated — Higher risk than local-only issues.
  3. Public-facing services — Internet-exposed = highest priority.
  4. Known exploits — Check if Metasploit has a module. If yes, it's urgent.
  5. Compliance violations — Required for regulatory audits.
💡 Pro Tip: Cross-reference Nessus findings with searchsploit or exploit-db.com to see if a public exploit exists. That instantly tells you which findings are most dangerous.

14 · NESSUS API

🔌 Nessus REST API

Nessus ships with a comprehensive REST API that lets you automate scans, pull results, and integrate with other tools. Perfect for CI/CD pipelines and custom dashboards.

# Authenticate (get session token) curl -k -X POST https://localhost:8834/session \ -H "Content-Type: application/json" \ -d '{"username":"admin","password":"yourpass"}' # List scans curl -k -X GET https://localhost:8834/scans \ -H "X-Cookie: token=YOUR_TOKEN" # Launch a scan curl -k -X POST https://localhost:8834/scans/1/launch \ -H "X-Cookie: token=YOUR_TOKEN" # Get scan results curl -k -X GET https://localhost:8834/scans/1 \ -H "X-Cookie: token=YOUR_TOKEN" # Export a scan curl -k -X POST https://localhost:8834/scans/1/export \ -H "X-Cookie: token=YOUR_TOKEN" \ -d '{"format":"nessus"}'
💡 Note: The Nessus API uses port 8834 (HTTPS) and requires authentication via session token. Full docs are available on the Nessus web interface under "API Documentation".
15 · BEST PRACTICES

✅ Nessus Best Practices

  1. Always use authenticated scans when possible — far more accurate.
  2. Update plugins weekly — New vulnerabilities are added daily.
  3. Schedule regular scans — Daily for critical assets, weekly for others.
  4. Use scan policies — Create reusable templates per network segment.
  5. Tune false positives — Mark as "accepted risk" to reduce noise.
  6. Enable Safe Checks — On production networks to avoid disruptions.
  7. Throttle on sensitive networks — Don't hammer fragile systems.
  8. Correlate with Metasploit — Export findings, verify with exploits (in lab).
  9. Document remediation — Track fixes and re-scan to confirm.
  10. Use API for automation — Integrate into CI/CD pipelines.

16 · LEGAL & ETHICS

⚖️ Legal & Ethical Boundaries

⚠️ Critical Warning: Nessus scans generate significant network traffic and can crash fragile systems. Never scan systems you don't own or have explicit written permission to test. Unauthorized scanning is a crime in many jurisdictions.

Before You Scan

  • Get written authorization — Signed scope document.
  • Define the target range — Only scan approved IPs.
  • Agree on timing — Off-hours to avoid disruption.
  • Warn the SOC/IT team — So they don't panic.
  • Have a rollback plan — In case something breaks.

17 · CONCLUSION

🎓 Final Thoughts

Nessus is the gold-standard vulnerability scanner in cybersecurity. Every professional pentester, security analyst, and compliance auditor has used it. It's fast, accurate, and covers more vulnerabilities than any other tool.

For ethical hackers, Nessus is a force multiplier. It finds the easy stuff — missing patches, weak configs, default creds — so you can focus your time on exploitation, logic flaws, and creative attacks. Combined with Metasploit and Burp Suite, it forms the core toolkit of modern pentesting.

The learning journey:

  1. Install Nessus Essentials — Free forever for 16 IPs.
  2. Scan your own lab — Start with Metasploitable or DVWA.
  3. Learn to read results — Prioritize by severity and exploitability.
  4. Practice authenticated scans — This is where the real value is.
  5. Automate with the API — Integrate with your workflow.
  6. Get certified — Tenable offers free training on Nessus.
🚀 Next Steps: Install Nessus Essentials today, spin up a Metasploitable VM, and run your first scan. Read every finding. Then use Metasploit to verify them. Within weeks, you'll be a vulnerability assessment pro.
